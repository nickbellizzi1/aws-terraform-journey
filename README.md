# AWS + Terraform - Learning in Public

I'm an infrastructure/network engineer with no prior Terraform or IaC experience, learning AWS and Terraform from the ground up while pursuing (and having earned) the AWS Solutions Architect Associate certification. This repo is the trail of that - each folder is a step up in complexity, kept and documented as-is (including the confusing parts), rather than cleaned up after the fact.

## Progress

- [x] `lesson-1` - Terraform basics: providers, resources, the init/plan/apply/destroy workflow, and a first real EC2 instance
- [x] `lesson-2` - Custom VPC with public/private subnets
- [ ] `lesson-3` - Load balancer + autoscaling group
- [ ] `lesson-4` - Full 3-tier app: ALB -> ECS Fargate -> RDS, modularized

Each folder has its own README with setup steps and a "what confused me / what clicked" section - the point isn't a polished final answer, it's showing the actual learning process.

## Why document it this way

Most portfolio repos show a finished result with no visibility into how it got there. This one is the opposite on purpose - it's meant to demonstrate that I can pick up unfamiliar infrastructure tooling methodically, not just that I can copy a tutorial.

## Background

Coming from 8+ years of on-prem/hybrid infrastructure and network engineering (MSP environments), currently building out hands-on AWS and Terraform skills to move into a cloud infrastructure role.
